NestDoorbellGateway

個人自用的 Google Nest 門鈴事件整合工具，透過 Windows 電腦上的本機閘道，協助 Android 時鐘裝置接收門鈴通知，並視設定開啟 Google Home App、Google Home 網頁或支援的攝影機即時畫面。

本專案為獨立開發的私人用途工具，並非 Google LLC 或 Google Nest 官方推出、贊助或認證的產品。

專案介紹與用途

多門鈴辨識取得已授權的 Nest 裝置資訊，接收門鈴按壓事件。
Windows 閘道在使用者自己的 Windows 電腦運作，將事件送往區域網路內的 Android 裝置。
Android 待機時鐘平時顯示時鐘；收到事件後，依設定開啟相應的觀看介面。

使用者需自行擁有或管理相容的 Google Nest 裝置、Google 帳號與授權設定。影像串流、按鈴事件或 Google Home 畫面開啟功能是否可用，取決於裝置型號、Google API 權限及 Android 系統限制。

若透過 Google Home 官方 App 或網站進行麥克風雙向對話，該功能由 Google Home 提供，並非本專案自行提供門鈴語音回傳 API。

本網站主要用於說明專案、隱私權政策和服務條款；本網站本身不會要求你輸入 Google 密碼、OAuth Client Secret、Refresh Token 或門鈴配對金鑰。

隱私權政策（Privacy Policy）

最後更新日期：2026 年 10 月 17 日

本政策說明 NestDoorbellGateway（包含 Windows Nest API 閘道與配套 Android 時鐘 App）如何在使用者授權下存取、使用、保存及刪除資料。此專案主要供開發者本人與獲准使用的家庭成員於私人環境中使用。

1. 可能存取的資料

  • Google 授權資訊：OAuth 用戶端設定、授權取得的存取權杖及更新權杖，用於向 Google Smart Device Management（SDM）API 請求已授權資料。
  • 裝置資料：已授權 Nest 裝置的識別碼、名稱、類型及可用的相機／門鈴功能。
  • 門鈴事件：按鈴事件對應的裝置識別碼、事件識別資訊及時間，用於通知指定的 Android 裝置。
  • 攝影機影音：只有使用者主動啟用且裝置/API 支援時，才可能建立短暫的即時影像或接收音訊連線；並不表示所有裝置都支援。
  • Android 本機資訊：時鐘外觀設定、選擇的門鈴動作、API 閘道網址、配對資訊及排錯所需的近期通知狀態。若授予 Android 通知存取權限，系統層級會讓服務取得通知資訊，程式預定用於辨識 Google Home 相關通知。

2. 使用目的與限制

上述資料僅用於：辨識已授權的門鈴、接收按鈴事件、在私人網路通知使用者、依使用者設定顯示相關影像或開啟 Google Home，以及故障排除。本專案不以 Google Nest 資料建立廣告輪廓，不出售使用者資料，也不將資料提供給資料經紀商。

從 Google API 取得的資料僅用於使用者明確授權的功能，不會轉作與門鈴通知或裝置管理無關的用途。若日後擴增收集或使用方式，應先更新本政策並取得必要的使用者同意。

3. 儲存位置與保留時間

  • OAuth Client Secret、Refresh Token 及閘道配對金鑰等私人設定，保存在使用者自行管理的 Windows 電腦設定檔中；請勿將該檔案上傳公開儲存庫。
  • Windows 閘道目前以記憶體緩存近期按鈴事件（最多約 400 筆），供 Android 平板讀取；服務重啟會清空此記憶體緩存。
  • Android 時鐘的個人化設定與診斷資訊可能保存在該裝置的本機 App 資料中，直到使用者清除資料、解除安裝或自行刪除相關備份。
  • Google Cloud Pub/Sub 內的訊息以及使用者自行建立的備份，其保存期間依使用者在相應平台的設定而定，不受本機緩存上限限制。

4. 網路傳輸與第三方服務

Windows 閘道會透過 HTTPS 呼叫 Google OAuth、SDM API 與 Google Cloud Pub/Sub。Android 與 Windows 閘道之間可使用私人區域網路 HTTP；若使用 HTTP，該段連線並未加密，應僅在受信任的私人網路使用，避免將閘道直接開放到公共網際網路。如需遠端使用，應另行設置 HTTPS 或受保護的 VPN。

若選擇使用 Google Home App／網頁進行觀看或對講，相關 Google 帳號登入、攝影機及麥克風作業由 Google 服務處理，並受 Google 隱私權政策規範。若本頁部署在 GitHub Pages，網站託管端可能依其自身政策處理連線紀錄；本頁不包含第三方追蹤或廣告腳本。

5. 資料分享與安全

本專案不設立集中式雲端資料庫以收集各家庭的門鈴資料。裝置資訊會為實現功能，在使用者授權下經 Google API、使用者自行設定的 Google Cloud 專案、Windows 閘道和已配對的 Android 裝置之間流動。使用者應妥善保護 Windows 系統帳號、API 私鑰、配對金鑰及內部網路。沒有任何網路或儲存方式能保證絕對安全。

6. 如何撤銷授權或刪除資料

  1. 可至 Google 帳號的第三方連線管理撤銷本專案授權，或在 Device Access 的授權管理介面移除存取。
  2. 停止 Windows 閘道，備份必要資料後刪除本機的 gateway_config.json、私人金鑰及不再需要的備份；先確認檔案所在位置，勿誤刪其他專案設定。
  3. 在 Android 系統設定中清除本 App 的本機資料，或解除安裝 App；如需保留時鐘配置，請先使用 App 支援的備份方式。
  4. 如已自行建立 Pub/Sub 訂閱或其他 Google Cloud 資源，可到自己的 Google Cloud 專案停用或刪除不再需要的資源，並檢查相關費用設定。
